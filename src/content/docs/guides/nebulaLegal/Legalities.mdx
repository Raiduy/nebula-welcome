Yes, there is some small print involved. Most of it is to protect you as user and to make sure the Network Institute delivers what it claims to deliver. 
Note that by accessing, using or purchasing the Nebula Research Platform, you consent to all of these Terms and policies. So, if you do not agree with any of those, please do not access, use or purchase the Nebula Research Platform.

We've also got a handy check list (from the RUG) to help you decide if your data needs a Data Protection Impact Assessment (DPIA). Please note that at this moment it is not allowed to use sensitive data with Nebula!

If you have any questions about these documents or about sensitive data please contact us at nebula.cs@vu.nl.

Please note that these documents are in a Draft status.
